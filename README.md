# Five Nights at Freddy's 1 — huEVO Edition (@majestic)

Полная копия страницы игры **Five Nights at Freddy's 1** с сайта
`https://kolyadual.github.io/dualgamingcentre/games/fnaf1/` (HTML5-порт Clickteam Fusion,
загрузчик «COMPLETE COLLECTION»), подготовленная для добавления
в приложения **huEVO** ([huevo.su](https://huevo.su/)) от имени разработчика **@majestic**.

Загрузочный экран, вёрстка, картинки, favicon — это часть исходного сайта;
внутри архива (`src/resources.zip.part*`) — сама игра.

## Выкладка на GitHub Pages

1. Создай **публичный** репозиторий на github.com (например `fnaf1`) и залей ВСЕ файлы этой папки в корень репо
   (`index.html`, `favicon.ico`, `resources/`, `src/`, `huevo.js`; README класть не обязательно).
   Самый простой вариант без git CLI — загрузить файлы через веб-интерфейс (Add file → Upload files),
   либо через GitHub API токеном (PUT /repos/{owner}/{repo}/contents/{path}, части по 8,4 МБ проходят).
2. Включи Pages: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Через ~1 минуту сайт будет доступен по адресу `https://<user>.github.io/fnaf1/` — проверь, что игра запускается.
4. Обнови `og:url` в `index.html` под фактический адрес (одна строчка).

Проверка после выкладки (все файлы должны отдаваться 200):
`https://<user>.github.io/fnaf1/src/resources.zip.part1` … `part20`, `src/Runtime.js`, `resources/title.png`.

## Добавление игры в huEVO

1. Открой [huevo.su/apps](https://huevo.su/apps) → **Создать**:
   - Тип: **«Игра»**;
   - Название: например `FNAF 1` (заменяемое);
   - Адрес игры: `https://<user>.github.io/fnaf1/`.
2. В настройках приложения:
   - «Фрейм игры»: **16:9** (канва игры 1280×720);
   - Логотип (квадрат ≥200px) и баннеры (4:3 ≥400px, 16:9 ≥640px) — подготовь сам (например, из кадров меню);
   - Автор игры: укажи свой профиль (@majestic);
   - Теги — по вкусу.
3. Открой страницу созданного приложения → **«Играть»** (test-режим — видно только тебе и тестировщикам).
   Игра должна запуститься и «дожевать» 167 МБ и загрузиться так же, как локально.
4. Проверь поведение huEVO:
   - при любом диалоге huEVO поверх игры (share/подтверждение оплаты) — игра ставится на паузу,
     после закрытия диалога — продолжается (`huevo.js`);
   - переключение вкладки huEVO — то же самое;
   - консоль: `[huEVO] подключено, запуск mode=test` (режим test у неподмодерированных приложений).
5. Отправь приложение на модерацию во вкладке «Публикация». После одобрения станет доступно всем.

## Технические мелочи

* SDK подключается строго с домена huEVO:
  `https://huevo.su/static/js/huevo-apps-v1.js` c `data-origins="huevo.departament.site"` (второй домен huEVO).
* `huevo.js` ставит игру на паузу, только когда huEVO открывает диалог или вкладка скрыта. Реализация:
  перехват игрового цикла Clickteam Fusion (именованная функция `updateApplication`) — только он.
  В остальное время поведение страницы 1-в-1 с оригиналом.
* Полноэкранный режим — комбо `-` + `=` (как в оригинале). Во фрейме huEVO запрос на полный экран
  должен быть разрешён родителем; если браузер его не даёт, запрос просто отклоняется — ничего не ломается.
* Ссылка нижнего баннера → `https://huevo.su/majestic` (новая вкладка, `target="_blank"`).
* Права: Five Nights at Freddy's — © Scott Cawthon. HTML5-порт — by irv77 (комментарий в `index.html` сохранён).
  Это фан-страница для huEVO, без коммерческого использования.
